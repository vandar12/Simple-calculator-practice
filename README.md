# 🧮 Simple Calculator


A simple calculator made with Python. It lets users add, subtract, multiply, and divide two numbers to see the result. If they put an invalid option the program will show error message.

## ✨ Features
- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
⚠️ Shows an error message if the user selects an invalid option

## 🚀 How to Use
1. ▶️ Run the Python program.
2. 🔢 Choose an operation from 1 to 4.
3. ✏️ Enter the first number.
4. ✏️ Enter the second number.
✅ The program will calculate and show the result.
